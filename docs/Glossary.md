# Глоссарий

- **Флотилия**: Группа рыболовных судов (траулеров), управляемых централизованно для организации поиска и отлова рыбы.
- **Траулер**: Тип рыболовного судна, предназначенного для траления – специальной рыболовной сетью (тралом) по дну или в толще воды для лова рыбы.
- **Банка**: Мелководный участок моря, где сосредоточены косяки рыбы и где осуществляется лов. Обычно имеет собственное географическое название.
- **Рейс**: Плавание траулера в море с целью поиска и отлова рыбы. Характеризуется датой выхода в море, датой возвращения и посещенными банками.
- **Улов**: Количество рыбы, пойманной за один рейс или за определённый период времени. Может характеризоваться названием, количеством (в кг) и качеством.
- **Член команды (экипажа)**: Работник, находящийся на борту траулера во время рейса. Включает различные должности, например, капитан, матрос, старший помощник и т.д.
- **Капитан**: Главное лицо на траулере, отвечающее за безопасность рейса, управление судном и организацию лова.
- **Водоизмещение**: Масса воды, которую вытесняет судно, используется как мера его размера и грузоподъёмности.
- **Должность (в команде)**: Конкретная роль члена экипажа на траулере (например, капитан, матрос, радист).
- **Бонус**: Дополнительная выплата члену экипажа, зависящая от результатов работы (например, за перевыполнение плана по улову).
- **База данных (БД)**: Организованная коллекция информации, хранящаяся в цифровом виде. В проекте используется SQLite.
- **SQLite**: Встраиваемая система управления базами данных (СУБД), не требующая отдельного серверного процесса.
- **CRUD**: Аббревиатура, обозначающая четыре основные операции с данными: Create (создать), Read (прочитать), Update (обновить), Delete (удалить).
- **Аутентификация**: Процесс проверки личности пользователя (обычно с помощью имени пользователя и пароля).
- **Авторизация**: Процесс предоставления пользователю доступа к определённым ресурсам или функциям системы после успешной аутентификации.
- **Роли (пользователя)**: Категории пользователей системы, определяющие уровень их доступа. В проекте: admin, crew.
